# SEO webmaster rules

Evaluate every SEO task against the [full ranking factors](references/full-ranking-factors.md). Use the original numbers and signed ratings so a reader can trace each finding. Treat the ratings as historical priorities. Never add them into a ranking prediction.

## Set priorities

| Classic rating | Source factors | Action |
| --- | --- | --- |
| +3 | Titles, URLs and headings (1, 2, 5, 59) | Make the page topic clear in the title, slug and relevant headings. Preserve established URLs unless a change justifies a migration. |
| +3 | Inbound anchor text and relevant sources (17–19), unique content (39), site accessibility (60) | Earn editorial references with original material. Verify that intended landing pages respond and expose readable content to crawlers. |
| +2 | Opening text and image descriptions (6–7), internal anchors and surrounding text (22–23) | Answer the reader early. Describe informative images and give links enough context to predict their destination. |
| +2 | Sitemap and site theme (61, 64) | Check that the sitemap lists intended canonical URLs and that related pages are easy to reach. |
| -2 | Keyword dilution (15), content separation (45), poor coding and design (46), frames and Flash (56–57), session IDs and crawl bans (75–76) | Warn against the harmful use. Focus each page, expose useful HTML, use stable URLs and correct unintended crawl blocks. |
| -3 | Keyword stuffing (16), outbound link farms, cross-linking schemes and single-pixel links (32–34) | Refuse manipulation. Replace repetitive copy and manufactured endorsements with natural language and editorial links. |
| -3 | Illegal content, invisible text, cloaking, doorways and duplicate content (47–51), Flash home pages (58), misapplied redirects (77) | Warn against the technique and refuse to recommend it. Offer a lawful, accessible page that delivers what the visitor requested. |

## Conduct the review

1. Identify the audience, search intent and available evidence. Use supplied HTML, copy, crawl results, link exports or performance reports. Mark unavailable evidence as unverified.
2. Open the full reference before recommending changes. Screen all 77 rows for a site-wide audit. For a narrower task, select applicable rows across the six groups and state the scope. Evaluate proposed copy or code as well as existing material.
3. Address evidenced harm first, then prioritize applicable +3 and +2 opportunities. Prefer sustainable, white-hat changes. Never recommend a -2 or -3 technique. When asked for one, name the factor, warn about the specific consequence, decline the tactic and give a practical alternative.
4. Check intent and implementation before assigning a negative finding. Distinguish unsolicited inbound links (29) from deliberate outbound participation (32), accessible screen-reader labels from deceptive hidden text (48), and legitimate migrations from deceptive redirects (77). For normal product variants, evaluate canonicalization under factor 51. Avoid implying an automatic penalty.
5. Apply modern guidance wherever an old description conflicts with current practice. Avoid density quotas, link-volume targets, domain-extension preferences, cosmetic date changes and fixed title lengths. Inspect experience, expertise, authoritativeness and trustworthiness (E-E-A-T) through evidence appropriate to the page, such as first-hand testing, named sources or accountable authorship. Evaluate whether the content actually answers the visitor's question.
6. Check mobile usability and Core Web Vitals when relevant. Use field data for loading (LCP), responsiveness (INP) and visual stability (CLS). Label lab diagnostics separately. Treat E-E-A-T as a quality framework and avoid assigning any modern signal a classic score or a universal ranking weight.
7. Report each material finding with its page or evidence, factor number, classic rating, action and verification step. Separate modern observations from source-rated findings. For a writing request, deliver the revised copy and a short rationale. For an audit, order findings by priority and identify missing evidence that could change the conclusion.
